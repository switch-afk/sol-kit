# sol-kit

One command for a set of small Solana CLI tools.

```
npx sol-kit --help
npx sol-kit list
```

## Tools

`sol-kit list` shows every tool with its short alias:

| Alias | Tool |
| --- | --- |
| tx | sol-tx-explain |
| watch | sol-tx-watch |
| prog | sol-program-info |
| fee | sol-priority-fee |
| rent | sol-rent-reclaim |
| idl | sol-idl-peek |
| pda | sol-pda |
| epoch | sol-epoch |
| stake | sol-stake-info |
| holders | sol-holders |

## Status

Early release. Running a tool through sol-kit comes next.

Node.js 18 or newer. No dependencies.
